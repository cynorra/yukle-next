# Play Store Listing — 日本語 (Japan) [ja-JP]

## Title (19/30 chars)
Loadly: トラック荷物検索・求荷

## Short description (38/80 chars)
トラック運転手・運送会社向け荷物探し。帰り荷を確保し空車走行を解消、直談判。

## Full description
Loadlyは、トラックドライバー、個人事業主、運送会社と荷主を直接つなぐ配送マッチングアプリです。希望の運行ルート、車両タイプ、積載量に合わせて最適な荷物をスピーディーに検索し、空車回送を削減します。

✓ かんたん荷物検索：大型、中型、平ボディ、ウイング車、冷凍冷蔵車に対応
✓ ダイレクトチャット：荷主と直接メッセージで運賃や積込条件を交渉可能
✓ ルート＆重量絞り込み：発着地や積載重量から最適な帰り荷を素早く抽出
✓ 新着プッシュ通知：設定した配送ルートに新しい荷物が出たら即座にお知らせ
✓ 55言語対応の運送ガイド：運行規制、過積載ルール、休憩施設情報を網羅

もう空車で走る必要はありません。今すぐLoadlyをダウンロードして、次の荷物を確保しましょう！

## Keyword rationale
日本のドライバーは企業向けの「求荷求車システム」ではなく、「トラック荷物」「帰り荷」「運送」「空車」といった日常語で検索する。
