## Title (18/30 chars)
Loadly: 找貨車貨源、卡車載貨

## Short description (35/80 chars)
為貨車、卡車司機尋找即時貨源回頭車。免跑空車，直接與貨主即時通訊洽談。

## Full description
Loadly 是專為大貨車、卡車、聯結車及貨車司機設計的載貨平台。直接配對貨主與司機，幫助您輕鬆尋找回頭車貨源，減少空車率，提升每趟趟次的載貨收入。

✓ 即時貨源搜尋：支援聯結車、大貨車、廂式貨車、冷凍車及各型板車
✓ 司機直接通話：無需經過抽成仲介，直接與貨主在線談定運費及載運細節
✓ 路線與噸數篩選：依據起迄地點、載重噸數、車輛規格精準匹配
✓ 即時推播通知：當您常跑的路線有新發出貨源時，第一時間彈出提醒
✓ 55種語言物流手冊：跨區行車法規、地磅站規範與載運標準指引

別再開著空車回程。立即下載 Loadly，隨時隨地用手機接單找貨！

## Keyword rationale
台灣的卡車司機直接搜尋「找貨車貨源」、「卡車載貨」、「回頭車」和「空車」，而非「車貨媒合平台」這類企業用語。
